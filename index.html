COMPLETED - FINAL YEAR PROJECT

RoadSense AI - Real-Time Road Damage Detection

Developed a real-time road damage detection system using a custom-trained YOLOv8n model on a Raspberry Pi 4. The project combines edge inference with a software pipeline using Firebase, SQLite, and a Flask REST API, connected to a React.js dashboard for monitoring. GPS and MPU6050 IMU sensor integration supports damage localisation. The model was trained using the Rome/Sacrofano dataset containing 2,009 images across three damage classes. The project gave me practical exposure to computer vision, model integration, edge computing, sensor data, and the challenges of building an end-to-end intelligent application.

COMPLETED - MINI PROJECT

RFID-Enabled Digital Framework for Rabies Surveillance

Developed an IoT-based healthcare monitoring project designed to improve patient identification and digital rabies surveillance recordkeeping. The system uses an ESP32, MFRC522 RFID reader, R307 fingerprint sensor, OLED status display, and Firebase Realtime Database. Embedded C firmware coordinates RFID scanning, fingerprint verification, status display, and Wi-Fi-based cloud synchronisation. The project explores replacing manual paper-based recordkeeping with a digital monitoring workflow.
